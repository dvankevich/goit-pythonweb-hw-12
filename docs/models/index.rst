Overview
--------

The application uses SQLAlchemy ORM models to define the database schema. Each model includes:

* **User Model**: Manages user authentication, roles, and user information
* **Contact Model**: Stores contact information associated with users

Both models follow Google-style docstring conventions and include comprehensive documentation for all methods and attributes.
