Overview
--------

Utility functions provide helper functionality and administrative tools for the application:

* **Create Admin Utility**: Script for creating the initial admin user

These utilities are typically standalone scripts or helper functions that support the main application functionality, such as database initialization, administrative tasks, and common operations used across multiple modules.
